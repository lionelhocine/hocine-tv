# HoC!Ne TV - Android TV app

- Remote playlist: `Config.kt` -> `PLAYLIST_URL` (points to `channels.json` in this repo, raw link).
  The repository must be PUBLIC for the raw link to work.
- Edit `channels.json` on GitHub to change categories / channels / links / branding. No new APK needed.
- Build: GitHub > Actions > Build APK > Run workflow > download artifact `HoCiNe-TV-apk`.
